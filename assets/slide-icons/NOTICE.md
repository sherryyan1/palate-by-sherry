# Optional slide icons

These 14 unmodified SVGs come from [Lucide's official repository](https://github.com/lucide-icons/lucide/tree/1ef60af944de207e0d5176905a0759ba12e6ee8d/icons), pinned to commit [`1ef60af944de207e0d5176905a0759ba12e6ee8d`](https://github.com/lucide-icons/lucide/commit/1ef60af944de207e0d5176905a0759ba12e6ee8d). The complete upstream [LICENSE](LICENSE), including the ISC license and the MIT notice for Feather-derived icons, accompanies the assets. Each SVG retains its upstream filename and bytes.

This is a small, coherent starting set for explanatory slide graphics. It does not prescribe a slide style, require an icon on every page or make the README's icon choices rules for slides. Select an icon only when its depicted object or action helps explain the supplied research; the accompanying label establishes its intended meaning.

The files are available offline and require no JavaScript package, font, remote resource or other display dependency. All use a `0 0 24 24` viewBox, a stroke width of `2` and rounded outline strokes. Their `currentColor` stroke is unchanged from upstream. Before importing one into PowerPoint or Keynote, create a task-local copy with an explicit stroke color suited to the slide; keep these originals unchanged and review the actual imported appearance. Keep labels editable where feasible. An imported SVG remains an image unless its conversion to editable native objects has been performed and checked.

An icon identifies a subject; it does not supply evidence, a verified mechanism or a quantitative result. Preserve the source-supported relationships and scientific qualifications in the surrounding explanation. Include this notice and the full license when redistributing the resource set or a derivative asset collection.
