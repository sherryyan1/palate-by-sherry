# Finding icons and country identifiers

Choose an asset for the explanation it supports. A useful icon depicts a relevant object or action, while a flag can help listeners locate a country in a comparison. Neither supplies scientific evidence. Plan the icon's [supporting role and scale](visual-storytelling.md#keep-icons-in-a-supporting-role) before sourcing it: normally a compact cue inside a flowchart or before a subheading or section label. A large main visual calls for an explanatory illustration or schematic, not an enlarged stock icon. Follow [visual storytelling](visual-storytelling.md) for the role of the graphic and the [host workflow](host-workflows.md) for the tools and authorized environment available to the task.

## Find a coherent set of icons

Flaticon is an optional source when the available tools and account permissions allow its use. Search for the concrete research object or action, then look within one suitable pack or family for related assets. Compare what the drawing actually depicts, rather than trusting its search tags. Prefer a coherent set with compatible stroke weight, fill treatment, perspective and optical size; mix sources only when the resulting objects still read as one visual vocabulary.

Use generic descriptive search terms. Do not upload an unpublished figure, manuscript or private research text to an asset service merely to find an icon. Reuse the user's authorized local assets when suitable. The [bundled icons](../assets/slide-icons/NOTICE.md) and native drawings remain useful offline alternatives when online access or a suitable license is unavailable.

| Available route | What the agent can do | What it must establish |
| :--- | :--- | :--- |
| Host search or browser tools | Find relevant Flaticon asset pages and inspect the available packs, formats and license information. | Use ordinary permitted access. A preview or search thumbnail is not a licensed downloaded asset. Complete a permitted download before placing it. |
| An explicitly configured official API | Search and retrieve assets through that API's documented operations. | Verify actual access, download entitlement and the applicable license. Do not assume that a website subscription includes API access. |
| A supplied asset or download | Inspect the file and use it where its content and permission fit the task. | Retain its provenance and required credit; user-supplied does not mean unrestricted redistribution. |

Flaticon's current site links to the [official Icons API](https://docs.magnific.com/api-reference/icons/icons-api), which documents authenticated search, retrieval and download. Provider endpoints, plans and entitlements can change, so consult the current official documentation when configuring access. This skill does not include a Flaticon client, API key or tested account integration. Use a host's existing authorized capability rather than inventing an endpoint or extracting a private website API. If login, a purchase or new API access is necessary, explain that specific dependency and continue independent design work; do not claim a download occurred.

Before using an asset, check its page, actual download license and the intended delivery. Flaticon's [terms](https://www.flaticon.com/legal) distinguish free use with attribution from eligible Premium downloads without attribution and restrict redistribution. Follow the terms applicable to the particular asset and account; a Premium badge or an available SVG preview alone does not establish permission. Keep credits readable in a location permitted by the license, such as a visible credits slide when allowed. Do not silently place required attribution only in speaker notes.

Keep downloaded assets and licenses in the private task workspace, with a short asset record: source page, creator, asset identity, download date, license basis, required credit and output slide. An asset's permission for a finished presentation does not automatically allow bundling its source file into a public skill or icon library. Do not add Flaticon downloads to this repository or the runtime package without a separate redistribution review.

Use an authorized vector format where available, or a raster file with enough resolution at its placed size. Inspect imported SVGs for external resources or active content before use, keep scientific labels editable outside the image and check the actual application render. Never bypass a login, payment requirement, access restriction or download limit. A failed download is a reason to choose a permitted alternative, not to extract a protected preview.

## Use flags to aid country comparisons

When country-level results involve several countries, assess selected slides for small flag identifiers beside country names, table rows or comparison headings. Use them where repeated recognition helps the audience follow the evidence. A result chart that is already dense may work better with text labels and flags only in its surrounding country headings. More countries do not justify filling every page with flags.

| Decision | Treatment | Scientific and visual check |
| :--- | :--- | :--- |
| Identify a country | Pair a verified flag with an editable country name or defined code. | Match the exact geographic unit represented by the source. A region, income group or multinational aggregate does not acquire a country's flag. |
| Keep identifiers comparable | Use a consistent apparent height and optical weight, retaining each flag's correct proportions and colors. | Avoid stretching, circular crops that remove identifying features, arbitrary recoloring or using flag size to imply a quantity. |
| Place identifiers near results | Align the flag with its name and relevant row, panel or heading. | Preserve label-to-value associations, source order, units, uncertainty and ranking. Do not replace data marks, legends or heatmap colors with flags. |
| Support many countries | Select useful country-focused slides or groups and retain explicit text labels. | Do not hide results or exclude countries merely to create space for flags. Split or omit identifiers when density harms comparison. |

Verify both the source's geographic identity and the chosen asset. Do not guess a flag from an ambiguous abbreviation or substitute one for an unmatched territory or historical entity. Use the source's label without a flag while resolving a material ambiguity. For historical results, preserve the source's temporal meaning; a flag is an identifier, not evidence of a boundary or political status.

Prefer static vector or high-resolution assets from a consistent, licensed set over flag emoji, whose rendering varies across platforms. Record their source and required attribution like other assets. Check the actual presentation render for recognizability, alignment and contrast, including flags with white fields. A subtle neutral outline can improve separation without changing the flag itself.
