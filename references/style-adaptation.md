# Reference-based style adaptation

A reference is useful when it reveals a design choice that can explain the current research more effectively. Inspect its appearance and structure together, then identify what the arrangement helps the reader understand. Record the source identity, hash and one-based slide or PDF page in private task notes so that the observation remains traceable.

Keep the basis for each observation explicit. A visible arrangement, an inferred rationale, a template convention and an owner's stated preference provide different kinds of evidence. Editing remnants, overlapping animation states and rejected visuals should not become design goals simply because they appear in a reference.

## Compare the choice, keep the research stable

Use the same scientific content for alternatives so that a difference in design can be judged on its own merits. Change one consequential dimension at a time and inspect each version before showing it. Explain the choice through its effect on the reader, using the [writing style](writing-style.md) to connect the decision with its reason.

| Dimension | Question for comparison |
| :--- | :--- |
| Hierarchy | Can the reader locate the relevant evidence and interpretation? |
| Explanation density | Is enough reasoning visible for this audience and time? |
| Layout | Does the reading order express the scientific relationship? |
| Color mapping | Are categories distinguishable and consistent with the legend? |
| Graphic emphasis | Does the emphasis direct attention to a supported point? |

Ask a focused question about the actual alternative and its tradeoff. Wait for a submitted answer before treating a preference as confirmed; silence does not establish a choice.

## Apply feedback within its scope

Keep feedback and source-specific evidence private, and apply the preference within the context demonstrated by that evidence. Retain exceptions where a different audience, purpose or scientific relationship calls for another approach. A rejected example can identify a problem in that example without establishing a blanket ban on the technique.

When the decision library changes, preserve stable rule IDs and the distinction between primary style direction and contextual composition options. Recheck the affected transformation and its scientific content before updating the package and installed copy explicitly. Reference decks and review notes remain private source material rather than runtime dependencies.
