# Reference-based style adaptation

Inspect reference pages visually and structurally. Record the source identity, hash and one-based slide or PDF page in private task notes. Distinguish visible behavior, inferred rationale, template convention and explicit preference. Do not treat editing remnants, animation overlays or rejected visual examples as design goals.

Compare alternatives using the same scientific content. Change one consequential dimension at a time: hierarchy, explanation density, layout, palette mapping or graphic emphasis. Inspect every alternative before presenting it. Ask concise questions about the choice and its tradeoff; silence is not confirmation.

Keep feedback and source-specific evidence private. Apply a preference within its demonstrated context and retain exceptions. A rejected example does not establish a blanket ban on a visual technique.

When adapting rules, keep stable IDs and distinguish primary style choices from contextual composition options. Recheck the affected transformation and scientific content. Package and installed snapshots are updated explicitly; reference decks and review notes are not runtime dependencies.
